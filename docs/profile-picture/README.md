# Company profile picture (Gmail and other accounts)

Options for the owner to pick from, in the business card's colours (green #11261E, gold #C9AE72, cream #EEEFE6),
using the card's own masjid and carpet artwork. Each is 1024 × 1024 px, square (Gmail crops it to a circle), with
everything kept inside the circle. `.svg` versions are the same art in vector form.

- **A**: cream masjid with gold crescent, gold ring.
- **B**: the masjid standing on the gold carpet and its roll, as on the card front.
- **C**: gold masjid with cream crescent, gold ring.

`options.png` shows each one at full size and at inbox sizes (72, 40 and 28 px).

To use: Google Account → Personal info → Profile picture → Change → upload the PNG.
